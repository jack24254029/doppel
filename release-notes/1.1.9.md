# Doppel 1.1.9

- Installing a ChatGPT update no longer stops when the update ships a read-only file. ChatGPT 26.924 did, and Doppel could not clear the copied file metadata from it, so it refused to build every clone and left them on the old build, which then would not start. Doppel now makes its private working copy writable first. Your installed ChatGPT is never touched.
